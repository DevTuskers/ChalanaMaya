# Out of scope for now

These items are not planned in the current scope, including after the MVP unless the owner changes this document:

- Real-time collaboration, hosted sharing, and end-to-end encryption for shared boards.
- Shape libraries, library browsing, and reusable library publishing.
- AI or smart generation: text-to-diagram, Mermaid import, and wireframe-to-code.
- App-level extras: PWA or offline installation, internationalisation (i18n), and watermarks.

Local browser saving and file export remain in scope. A basic sketch-to-shape tool is included in the drawing specification; it does not imply a wider AI offering.
